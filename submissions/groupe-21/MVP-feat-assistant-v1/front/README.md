# Prototype assistant IA Caisse d'Epargne (Hackathon IA for Impact)

Maquette front, données fictives, aucune action bancaire réelle. Versions web et mobile (sélecteur en haut).

- Lancer avec le vrai assistant : `.venv/bin/python -m assistant` à la racine, puis http://localhost:8000
  (voir [../assistant/README.md](../assistant/README.md)). Ouvrir `index.html` seul : tout est scripté.
- Contexte et règles pour Claude Code : voir `CLAUDE.md`
- Base de données fictive (taux, prévisions, tarifs) : [../finance/README.md](../finance/README.md)
