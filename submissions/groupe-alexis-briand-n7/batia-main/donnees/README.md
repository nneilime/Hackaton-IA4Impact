# Données du défi BâtIA : non publiées

Le kit de données du défi Action Logement / In'li Sud-Ouest (« BâtIA ») a été remis aux participants du hackathon AI for Impact. Sa règle : **ces données ne quittent pas le cadre du hackathon**. Elles ne sont donc pas dans ce dépôt public, pas plus que les fichiers qui en sont tirés (scores par équipement, calendriers, rejeu).

Pour lancer l'application ou refaire les livrables, déposer ici le kit tel qu'il a été remis :

    donnees/kit-batia/donnees/01_residences.csv … 10_ref_*.csv
