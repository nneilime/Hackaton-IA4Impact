# Diapositives du pitch BâtIA

Version présentée : `effort-max/`, une scène fixe de 1920 × 1080.

```bash
cd pitch/effort-max
python3 -m http.server 4980 --bind 127.0.0.1
# ouvrir http://127.0.0.1:4980/  (flèches gauche et droite, F pour le plein écran, #6 dans l'adresse pour aller à la 6)
```

Tout est local (polices, photos, script) : ça marche sans connexion. Les photos viennent de Pexels, le détail est dans `effort-max/CREDITS.md`.
