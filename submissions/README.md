# Dépôts des participants

C'est ici que vous déposez votre travail pendant le hackathon.

Chaque participant ou équipe dispose d'un dossier, et **seul son auteur peut le modifier** :

- en solo : `submissions/<votre-pseudo-github>/`
- en équipe : `submissions/<nom-de-votre-equipe>/`

Pour commencer, copiez le modèle [`_template/README.md`](_template/README.md) dans votre dossier et
complétez-le. La procédure de dépôt complète est décrite dans
[`../CONTRIBUTING.md`](../CONTRIBUTING.md).

> Depuis l'[application des équipes](https://nneilime.github.io/Hackaton-IA4Impact/), un membre
> confirmé peut aussi **déposer directement un fichier `.zip`** : son contenu est extrait dans
> `submissions/<nom-de-votre-equipe>/`.

> Le dépôt passe par une Pull Request. Une vérification automatique s'assure que vous ne modifiez
> que votre propre dossier.
